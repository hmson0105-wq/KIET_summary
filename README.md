# KIET 2027 논술 준비 아카이브

KIET(산업연구원) 채용 논술시험 준비를 위한 개인 기록 저장소입니다.

## 구성

- `kiet_note_archive.html` — 기록 작성·복습·커버리지 매트릭스·사례모음·개요연습 기능이 담긴 아카이브 도구. 브라우저로 열면 바로 사용 가능 (데이터는 브라우저 저장소에 개인 보관).
- `notes/요일-분야/날짜.html` — 매일 아침 자동 브리핑(산업연구원·한국은행 등 보고서 요약)을 날짜별로 보관하는 폴더. 예: `notes/금-거시경제/20260821.html`

## 폴더 네이밍 규칙

`notes/` 하위 폴더명은 아카이브 도구의 요일별 주제 분류와 동일합니다.

| 폴더명 | 주제 |
|---|---|
| `월-주력산업` | 주력산업·제조업 정책 (반도체·자동차·조선 등) |
| `화-통상` | 통상·글로벌 공급망 |
| `수-중소벤처` | 중소·벤처기업 정책 |
| `목-에너지` | 에너지·탄소중립·지역균형발전 |
| `금-거시경제` | 거시경제·통계 이슈 |
| `토-통합` | 주간 통합·논술 개요 연습 |

파일명은 `YYYYMMDD.html` 형식입니다.

## 접근 방법

- 데스크탑: Claude Code에서 이 레포를 열어 노트 추가·커밋
- 데스크탑 미접속 환경(회사 등): [claude.ai/code](https://claude.ai/code)에서 동일 레포에 접근해 이어서 작업
